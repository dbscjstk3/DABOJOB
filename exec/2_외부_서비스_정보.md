# 외부 서비스 정보

## 개요
DABOJOB 프로젝트에서 사용하는 외부 서비스들의 가입 및 활용 정보를 정리한 문서입니다.

## OAuth2 인증 서비스

### 1. Google OAuth2
**서비스 제공자**: Google Cloud Platform
**용도**: 소셜 로그인 (Google 계정)
**공식 문서**: https://developers.google.com/identity/protocols/oauth2

#### 가입 및 설정 절차
1. **Google Cloud Console 접속**
   - https://console.cloud.google.com/ 접속
   - Google 계정으로 로그인

2. **프로젝트 생성**
   ```
   1) 새 프로젝트 생성 또는 기존 프로젝트 선택
   2) 프로젝트 이름: "DABOJOB" (또는 원하는 이름)
   ```

3. **OAuth 2.0 클라이언트 ID 생성**
   ```
   1) APIs & Services > Credentials 이동
   2) "Create Credentials" > "OAuth client ID" 선택
   3) Application type: "Web application" 선택
   4) Name: "DABOJOB Web Client"
   5) Authorized redirect URIs 추가:
      - http://localhost:8080/login/oauth2/code/google (개발)
      - https://your-domain.com/login/oauth2/code/google (운영)
   ```

4. **필요한 정보**
   - **Client ID**: `your_google_client_id`
   - **Client Secret**: `your_google_client_secret`
   - **Scope**: `profile,email`

---

**용도**: SSAFY 계정 연동

#### 가입 및 설정 절차

   - SSAFY 교육생 또는 관련자 자격 필요
   - 프로젝트 담당자에게 OAuth 앱 등록 신청

2. **앱 등록 정보**
   ```
   애플리케이션 이름: DABOJOB
   설명: AI 기반 기업 분석 및 채용 정보 플랫폼
   리다이렉트 URI: https://your-domain.com/login/oauth2/code/ssafy
   ```

3. **발급받는 정보**
   - **Client ID**: `your_ssafy_client_id`
   - **Client Secret**: `your_ssafy_client_secret`

## AI/ML 서비스

### 3. OpenAI GPT API
**서비스 제공자**: OpenAI
**용도**: 회사명 매핑, 텍스트 분석, 자연어 처리
**공식 문서**: https://platform.openai.com/docs

#### 가입 및 설정 절차
1. **OpenAI 계정 생성**
   - https://platform.openai.com/ 접속
   - 계정 생성 및 이메일 인증

2. **결제 정보 등록**
   ```
   1) Account > Billing 메뉴 이동
   2) 신용카드 등록 (Pay-as-you-go)
   3) 사용량 한도 설정 (예: $50/월)
   ```

3. **API 키 발급**
   ```
   1) Account > API Keys 메뉴 이동
   2) "Create new secret key" 클릭
   3) 키 이름: "DABOJOB-Production"
   4) 생성된 API 키 안전하게 보관
   ```

4. **사용 모델 및 설정**
   - **모델**: `gpt-3.5-turbo`
   - **예상 비용**: 월 $10-30 (사용량에 따라)

### 4. Ollama (Self-hosted LLM)
**서비스 제공자**: Ollama (오픈소스)
**용도**: 로컬 LLM 추론 (비용 절약)

## 클라우드 서비스

### 7. Amazon Web Services (AWS S3)
**서비스 제공자**: Amazon
**용도**: 파일 저장, 이미지 업로드
**공식 문서**: https://docs.aws.amazon.com/s3/

#### 가입 및 설정 절차
1. **AWS 계정 생성**
   ```
   1) https://aws.amazon.com/ 접속
   2) "AWS 계정 생성" 클릭
   3) 신용카드 등록 (프리티어 사용 시에도 필요)
   ```

2. **IAM 사용자 생성**
   ```
   1) AWS Console > IAM 서비스 이동
   2) Users > "Add user" 클릭
   3) 사용자 이름: "dabojob-s3-user"
   4) 권한: "AmazonS3FullAccess" 정책 연결
   ```

3. **S3 버킷 생성**
   ```
   1) AWS Console > S3 서비스 이동
   2) "Create bucket" 클릭
   3) 버킷 이름: "your-unique-bucket-name"
   4) 리전: "Asia Pacific (Seoul) ap-northeast-2"
   ```

4. **발급받는 정보**
   - **Access Key ID**: `your_aws_access_key_id`
   - **Secret Access Key**: `your_aws_secret_access_key`
   - **Region**: `ap-northeast-2`
   - **Bucket Name**: `your_s3_bucket_name`
