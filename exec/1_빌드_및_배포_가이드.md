## 아키텍처 개요

### 서비스 구성
1. **Spring Boot 서버** (포트: 8080)
   - 메인 API 서버
   - OAuth2 인증 (Google, SSAFY)
   - JWT 토큰 관리

2. **Private Python 서버들**
   - **Standardizer Server** (포트: 8000)
   - **Summary Server** (포트: 8100)
   - **News Summary Server** (포트: 8200)

3. **데이터베이스**
   - **MySQL 8.0.42** (Spring용, Private용)
   - **MongoDB 7.0.14** (Spring용)
   - **Redis 7-alpine** (캐싱, 세션)

4. **AI/ML 서비스**
   - **Ollama** (포트: 11434) - LLM 서비스

5. **웹 서버**
   - **Caddy 2** (포트: 80, 443) - 리버스 프록시

## 빌드 프로세스

### 1. 소스코드 클론
```bash
git clone [repository-url]
cd S13P21A402
```

### 2. 환경 변수 파일 설정
프로젝트 루트에 `.env.spring`과 `.env.private` 파일을 생성하고 위의 환경 변수를 설정합니다.

### 3. Spring Boot 서버 빌드
```bash
cd backend/spring-server
./gradlew clean build -x test
```

### 4. 빌드 특이점 (중요)
**반드시 다음 순서로 빌드 및 실행해야 합니다:**

#### 4-1. Ollama 모델 우선 실행
```bash
# 1단계: Ollama 서비스 먼저 시작 (모델 다운로드 시간 필요)
docker compose -f docker-compose.full.yml up -d ollama

# 모델 다운로드 대기 (5-10분 소요)
docker logs -f private-ollama

# 모델이 준비되면 전체 private 서비스 실행
docker compose -f docker-compose.full.yml --env-file .env.private up -d
```

#### 4-2. Spring 서버 실행 (선택사항)
```bash
# Spring 서버도 함께 실행하려면
docker compose -f docker-compose.spring.yml --env-file .env.spring up -d
```

```bash
# ============== Server (Spring) ==============
SERVER_PORT=8080

SPRING_DATASOURCE_USERNAME=your_mysql_user
SPRING_DATASOURCE_PASSWORD=your_mysql_password
SPRING_DATASOURCE_DRIVER_CLASS_NAME=com.mysql.cj.jdbc.Driver

# Hikari pool
SPRING_DATASOURCE_HIKARI_IDLE_TIMEOUT=300000
SPRING_DATASOURCE_HIKARI_MINIMUM_IDLE=3

SPRING_REDIS_PASSWORD=your_redis_password
SPRING_REDIS_DATABASE=1

# ============== MongoDB (초기화 & Spring 접속) ==============
# 공식 Mongo 이미지 초기화 키 (처음 볼륨 생성 시에만 적용)
MONGO_INITDB_ROOT_USERNAME=root

# (참고용) 프로젝트 내부에서 쓸 DB명

# Spring의 Mongo 접속 설정 (현재는 root로 연결)

SPRING_DATA_MONGODB_DATABASE=mainmongodb

# SPRING_DATA_MONGODB_URI=mongodb://root:your_mongo_password@mongo:27017/mainmongodb?authSource=admin

# --- SSAFY (커스텀 provider) ---
```

## 배포 시 특이사항

### 1. AI 모델 초기화
- Ollama 컨테이너 최초 실행 시 모델 다운로드 필요
- 모델 크기에 따라 초기화 시간 소요 (5-30분)
- 모델 목록:
  - `llama3.2:3b-instruct-fp16` (Summary용)
  - `qwen2.5:0.5b-instruct-fp16` (Standardizer, News용)

### 2. 데이터베이스 초기화
- MySQL은 초기 스키마 생성 필요
- Spring Boot는 `ddl-auto=none`으로 설정되어 수동 스키마 관리
- MongoDB는 첫 접속 시 자동 초기화

### 3. Frontend 빌드 (React + Vite)
```bash
cd frontend
npm install
npm run build

# Docker로 빌드하는 경우
docker build -t s13p21a402/frontend:latest .
```

### 4. SSL/TLS 설정
- Caddy를 통한 자동 HTTPS 인증서 발급
- 도메인 설정 시 `Caddyfile` 수정 필요

### 5. 메모리 요구사항
- Ollama 서비스: 최소 4GB RAM 권장
- 전체 시스템: 최소 8GB RAM 권장
